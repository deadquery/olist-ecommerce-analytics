# Olist E-Commerce Analytics

BI-аналитика бразильского e-commerce проекта на основе публичного датасета Olist.

## О проекте

Цель проекта — проанализировать продажи, клиентов, товарные категории, доставку и отзывы, определить ключевые показатели бизнеса и представить результаты в интерактивном Power BI-дашборде.

В рамках проекта выполнены:

- анализ выручки и количества заказов;
- анализ динамики продаж по месяцам;
- анализ товарных категорий;
- анализ повторных покупок;
- анализ сроков и своевременности доставки;
- анализ клиентских оценок;
- подготовка бизнес-инсайтов.

## Инструменты

- PostgreSQL
- SQL
- Power BI
- DAX
- Power Query

## Данные

В работе использован Brazilian E-Commerce Public Dataset by Olist.

Датасет содержит информацию о заказах, товарах, клиентах, продавцах, доставке и отзывах.

Для основного анализа использовались таблицы:

- `olist_orders_dataset`
- `olist_order_items_dataset`
- `olist_products_dataset`
- `olist_customers_dataset`
- `olist_order_reviews_dataset`
- `product_category_name_translation`

## Основные бизнес-инсайты

### 1. Объём продаж и средний чек

За анализируемый период было оформлено около 99 тыс. заказов на общую сумму около R$ 13,59 млн.

Средний чек составил около R$ 137,75, что характеризует модель с большим количеством относительно небольших заказов.

### 2. Динамика продаж

Месячная выручка демонстрирует существенный рост в течение 2017 года и достигает уровня около R$ 1 млн в отдельные месяцы начала 2018 года.

### 3. Концентрация выручки по категориям

Основная часть выручки формируется несколькими товарными категориями. Среди лидеров по выручке — watches_gifts, sports_leisure и toys.

### 4. Своевременность доставки

Среднее время доставки составило 12,5 дня.

Доля заказов, доставленных позже расчетной даты, составила 8,1%, поэтому своевременность доставки является значимым операционным показателем.

### 5. Доставка и оценки клиентов

Средняя оценка заказов, доставленных вовремя, выше средней оценки заказов с задержкой.

Это показывает связь между качеством доставки и удовлетворённостью клиентов и делает показатель своевременной доставки важным KPI.

### 6. Повторные покупки

Доля клиентов, совершивших более одной покупки, составила около 3,1%.

Это указывает на потенциал для развития инструментов удержания клиентов и стимулирования повторных покупок.
